# Деплой на Oracle Cloud (Always Free)

Цель: приложение работает 24/7 на бесплатной виртуалке, не зависит от твоего ноутбука.
Стоимость: 0 ₽ навсегда. Нужна карта для верификации (списаний нет).

## Что понадобится

- Аккаунт Oracle Cloud (регистрация ~10 минут, просят карту)
- Наш SSH-ключ (ниже) — чтобы я мог зайти на сервер и всё настроить
- ~30 минут

## Шаг 1. Регистрация

1. https://www.oracle.com/cloud/free/ → **Start for free**
2. Страна, e-mail, пароль. Карта нужна для проверки личности (обычно списывают и сразу возвращают $1).
3. Выбери **домашний регион** — чем ближе, тем быстрее сайт (например, `Germany Central (Frankfurt)` или `Switzerland North`).

## Шаг 2. Создать виртуалку

Консоль → **Compute → Instances → Create instance**.

| Поле | Значение |
|---|---|
| Name | `gruppa` |
| Image | **Ubuntu 24.04** (Canonical) |
| Shape | **VM.Standard.A1.Flex** — 1–2 OCPU, 6–12 GB (Always Free) |
| | если написано «out of capacity» — возьми **VM.Standard.E2.1.Micro** (тоже бесплатный) |
| Boot volume | 50 GB (по умолчанию) |

**Ключ доступа:** в блоке *Add SSH keys* выбери **Paste public keys** и вставь:

```

После создания запиши **Public IP address** — он понадобится.

## Шаг 3. Открыть порты 80 и 443

По умолчанию Oracle закрывает всё, кроме 22. Нужно открыть веб:

1. Открой свою инстанцию → вкладка **Networking** → **Virtual cloud network** → **Security Lists** → `Default Security List`
2. **Add Ingress Rules** и добавь два правила:

| Source CIDR | IP Protocol | Destination Port Range |
|---|---|---|
| `0.0.0.0/0` | TCP | `80` |
| `0.0.0.0/0` | TCP | `443` |

Без этого сайт не откроется снаружи — только по SSH.

## Если A1 недоступна

Ошибка `Out of capacity for shape VM.Standard.A1.Flex` — обычное дело, ARM-мощности разбирают.
Варианты:

1. Выбрать **VM.Standard.E2.1.Micro** — 1 ГБ RAM, для 30 человек с головой хватит.
2. Попробовать другой Availability Domain (в форме их три).
3. Подождать и попробовать позже.

## Что важно знать про Always Free

- Инстанс **не выключится** сам по себе, если не нажимать Stop.
- Если аккаунт не будет активности 30 дней, Oracle может уменьшить ресурсы — но для нашего случая это не критично.
- Карта не списывает деньги, пока ты не нажмёшь **Upgrade to Pay As You Go**.
