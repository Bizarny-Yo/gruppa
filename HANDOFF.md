## Публичный адрес

**https://gruppa-605x.serveousercontent.com**

Туннель: serveo.net, имя `gruppa-605x` закреплено за SSH-ключом пользователя
(ключ зарегистрирован в консоли serveo — вход через GitHub).

Важные грабли, уже пойманные:
- **ssh идёт на -p 443**: порт 22 блокируется, когда включён прокси (FlClash). Симптом — connect to host serveo.net port 22: Connection timed out`n- цель указывать `127.0.0.1`, не `localhost` — иначе IPv6 `::1` и 502
- serveo рвёт соединение каждые ~30 минут → нужен цикл переподключения (`run-all.ps1`)
- после обрыва serveo может **держать порт 80 за старым именем** (`remote port forwarding failed`).
  Тогда берём новое имя: `-R "gruppa-xxxxx:80:127.0.0.1:47824"`. Так потеряли `gruppa-pmi21`.
- Cloudflare-туннели на этой сети не работают: `Register tunnel error: context deadline exceeded`
- бесплатный serveo показывает посетителям страницу «Continue to Site»

**Автозапуск установлен:** `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\gruppa-autostart.vbs`
→ при входе в Windows поднимает `scripts\run-all.ps1` скрыто, без DSH.
Удалить: `scripts\install-autostart.ps1 -Uninstall`

## Кнопки на рабочем столе

На рабочем столе два ярлыка: **Запустить сайт.lnk** и **Остановить сайт.lnk**.
Они ведут на .cmd-файлы в папке проекта (не копии!).

Важно: не копировать .cmd на рабочий стол — внутри путь %~dp0scripts\... относительный,
и с рабочего стола он ищет Desktop\scripts\, которых нет. Кнопка молча не работает.
Если папку проекта перенести — ярлыки надо пересоздать.

## Как создать сессию для проверки

```powershell
node --input-type=module -e "const {db}=await import('./server/db.js'); const {randomBytes}=await import('node:crypto'); const u=db.prepare(\"SELECT id FROM users WHERE role='starosta'\").get(); const t=randomBytes(32).toString('hex'); db.prepare('INSERT INTO sessions (token,user_id,created_at,expires_at) VALUES (?,?,?,?)').run(t,u.id,new Date().toISOString(),new Date(Date.now()+3600e3).toISOString()); process.stdout.write(t)"
```

## Известные ограничения

1. **Сервер на ноутбуке** — выключил → сайта нет. Автозапуск спасает только после входа в Windows.
2. **serveo видит трафик** (TLS заканчивается у них). Свой VPS это убирает.
3. **Нет бэкапов** базы. Данные только на диске.
4. **Бан по имени** — можно вернуться под другим именем (нет подтверждения личности).
5. **Данные на диске не зашифрованы** (пароли — scrypt-хеши).

## Стиль работы, который зашёл пользователю

- Сначала проверить в коде/живьём, потом утверждать
- После изменений в UI — скриншот и проверка глазами
- Коротко объяснять «почему», а не только «что»
- Не выдумывать: не проверил — так и сказать
- Не трогать данные пользователя без нужды; тестовое — убирать за собой
